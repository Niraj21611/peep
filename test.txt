UI COMPONENT RULE:

Use shadcn/ui as the primary component library.

Before creating a custom UI component, check whether an appropriate shadcn/ui component already exists.

Prefer composing shadcn/ui primitives rather than creating duplicate components.

Use Tailwind CSS for styling and customization.

Use Lucide React for icons.

Do not introduce another UI component library.

Keep generated shadcn primitives inside:

src/components/ui/

Keep application-specific components inside their respective feature folders.

Now implement the complete Monthly Budget feature.

Use the provided Excel Budget screenshot as the functional reference.

The budget page should allow the user to define a monthly budget for each expense category.

IMPORTANT:

Budgets are dynamic.

If a new category is created, it must automatically become available for budgeting.

Do NOT hardcode categories into the budget page.

BUDGET MODEL:

A budget belongs to:

- authenticated user
- category
- month
- amount

There must be at most one budget for:

user + category + month

BUDGET PAGE:

Provide a month selector.

For the selected month show:

Category
Budget
Actual Spent
Remaining
% Used
Status
Notes

Similar conceptually to the Excel sheet.

CALCULATIONS:

Actual Spent should be calculated from transactions for:

- selected month
- selected category
- transaction type = EXPENSE

Remaining:

budget - actualSpent

% Used:

actualSpent / budget * 100

Avoid division by zero.

STATUS:

Possible states:

- No Budget
- Within Budget
- Near Limit
- Over Budget

Use sensible thresholds.

For example:

0-80% = Within Budget
80-100% = Near Limit
>100% = Over Budget

But keep these thresholds centralized so they can be changed later.

TOP SUMMARY:

Display:

- Total Budget
- Total Spent
- Total Remaining
- Overall Status

FEATURES:

1. Select month
2. Set budget
3. Edit budget
4. Remove budget
5. Automatically calculate actual spending
6. Show percentage used
7. Show status
8. Highlight over-budget categories

SERVER ACTIONS:

Use Server Actions for:

- create/update budget
- delete budget

All operations must verify authentication and ownership.

IMPORTANT:

Do not store Actual Spent, Remaining, Percentage Used, or Status in the database.

These are derived values.

The transaction data is the source of truth.
